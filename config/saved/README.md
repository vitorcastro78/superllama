# Saved LlamaServer configs

Snapshots copied from the production machine (`C:\LlamaServer\config`) so the saga (MTP, dual-GPU, MoE, TurboQuant, restores) stays reproducible.

- `profile-*` — named boot profiles
- `backup-pre-*` — pre-experiment backups
- `LAST_*.txt` — pointers to the last backup of each experiment
- `*.production-live` — live production env/preset at archive time
